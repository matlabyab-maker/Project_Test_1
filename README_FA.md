# دمو سبک کوهستان برفی ۱۹۴۲

این نسخه یک نمونه فنی کوچک برای ارزیابی روش‌های بهینه‌سازی است:
- یک هواپیمای پلیر
- چند خانه
- چند جاده
- یک پل
- زمین پایه با Plan ساده
- کوه‌های ساده
- مدل‌های مشترک و هندسه کم‌حجم
- بدون تکسچر و صدای خارجی

این فایل APK نیست؛ پروژه Godot 4 است و برای ساخت APK باید در Godot 4 باز و Export شود.
حجم APK نهایی به نسخه Godot، معماری CPU و تنظیمات Export وابسته است و از روی حجم این ZIP قابل نتیجه‌گیری نیست.
